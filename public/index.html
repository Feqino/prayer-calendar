Your calendar link

Add this once to Google or Apple Calendar. It refreshes on its own — you never do this again.

How do I add it?

Google Calendar (on a computer): Settings → Add calendar → From URL → paste → Add calendar.

iPhone / Apple: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste.

Outlook: Add calendar → Subscribe from web → paste.

Calendars re-check the link every several hours, so edits you make here show up on their next refresh — existing events are updated in place, not duplicated.

Location & calculation

The five prayers

Starts before = how many minutes before the adhan the event opens. Total length = how long the whole event runs.
Example: 10 before + 40 total = from 10 min before the adhan until 30 min after.
